# Codex session instructions

At the start of every Codex session in this repository, read and follow these project-local skills before doing any work:

1. `.agents/skills/caveman/SKILL.md`
2. `.agents/skills/ponytail/SKILL.md`
3. `.agents/skills/i-have-adhd/SKILL.md`

Treat all three skills as active for the entire session unless the user explicitly disables a mode as described in that skill.

The complete Caveman skill pack is installed in `.agents/skills/`. Before each task, inspect the available Caveman skill descriptions and read every supporting Caveman skill that matches the task. Keep each skill's bundled files and scripts available; do not replace the package with only the core `caveman` skill.
